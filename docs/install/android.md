# Android phone or tablet

The Android app is the same one used on TVs: **[Netfish-android.apk](https://github.com/ravifrancesco/netfish/releases/latest/download/Netfish-android.apk)**. It isn't on the Play Store, so Android asks once whether to allow installing it.

<img src="../screenshots/phone.jpg" alt="Netfish on a phone" width="300">

1. On the phone, open the link above (or the [Releases page](https://github.com/ravifrancesco/netfish/releases/latest)) and download **Netfish-android.apk**.
2. Open the downloaded file (from the browser's downloads or a notification).
3. Android says the browser isn't allowed to install apps: tap **Settings**, switch on **Allow from this source**, and go back.
4. Tap **Install**. If Google Play Protect warns about an unknown app, tap **More details → Install anyway**.
5. Open **Netfish**, enter your server's address (e.g. `192.168.1.50`) and sign in.

Films play with ExoPlayer and the device's hardware decoder, with every sound format (DTS, TrueHD, Dolby) decoded by the app, so the server sends files untouched. A film turns to landscape full screen.

**Downloads** for offline viewing: the **Download** button on any movie or episode; find them in the profile menu → **Downloads on this device**. Away from home, the app opens your downloads.

**Updating:** most new features arrive through your server, with no app update. When the app itself has something new worth having, Netfish says so on Home. From 0.6.3, **Update** there (or in **Settings → Android app**) downloads the new version and Android asks you to confirm; the first time, it asks to let Netfish install apps. Older versions: download and install the new APK the same way. Your sign-in and downloads are kept.
